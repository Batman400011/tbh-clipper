Read this before you download

One thing determines whether this feels fast or broken.

Check your processor cores first

The work is heavy arithmetic and it uses every core you have. We measured the same 2-hour recording on two computers:

Your computerA 2-hour recording
8 or more coresabout 5 hours
4 cores (thin laptop)about 34 hours

Three times the cores gave seven times the speed. Nothing is wrong with the slower machine — it is doing the same work correctly, with less to do it with.

To check yours: press Ctrl + Shift + Esc, click Performance, then CPU. Look for "Cores". Tell us that number in the questionnaire either way — knowing how it behaves on a small machine is one of the things we most need from this round.

Getting set up

Four steps. The third one is long but you can walk away from it.

2
Download it

One zip file. Unzip it somewhere permanent — not inside the Downloads folder, because it builds itself a home in whichever folder you leave it in.

Download for Windows Download for Mac

Mac — read before you download

Apple Silicon only (M1, M2, M3, M4), on macOS 14 or newer. The AI library this runs on no longer ships builds for Intel Macs, so an Intel Mac cannot install it at all — not slowly, not at all. Check: Apple menu → About This Mac → "Chip".

Unzip, then double-click Start TBH Clipper.command. If macOS says it "cannot be opened because it is from an unidentified developer": right-click it, choose Open, then Open again. One-time thing.

The Mac build is brand new and untested on a real Mac — we do not have one. The parts that make clips are the same code that already produced clips for one Mac tester; what is unproven is the installer. If it stops, a photo of the Terminal window is exactly what we need.

3
Run "Start TBH Clipper.bat"

First time it installs everything it needs — roughly 30 to 60 minutes and several gigabytes. Leave it running and go and do something else. Every launch after this one takes seconds.

Windows will say "Windows protected your PC". That appears for anything not bought from a big publisher. Click More info, then Run anyway.

4
Point it at a recording

Put a video in your Downloads folder and it appears in the app. Pick it, pick a style, and start. Start it before bed — this is an overnight job on any machine.

New in 1.5.0 — no account needed any more

Earlier versions asked you to make a Hugging Face account and create a token before speaker names would work. That step is gone. Speaker detection is now built in, needs no account and no internet, and runs on its own.

There is also a new question when you start a run — panel or interview. Tell it how many people talk in your recording and it tunes itself. Two people is the easier case and it does a noticeably better job when it knows.

Things that catch people out

Every one of these has already happened to someone. None are your fault.

  • Windows S Mode blocks it silently. If double-clicking the file does absolutely nothing — no error, no window — that is why. Settings → System → Activation → switch out of S Mode. It is free and one-way.
  • Don't let the computer sleep. A run does not count as activity, so a machine set to sleep after 30 minutes will stop overnight and throw away the hours it had done. Run Check Run Speed.bat — it offers to fix this for you.
  • An Ollama window may open offering a list of models and a sign-in. Close it and ignore it. You do not need an account, and the app downloads what it needs by itself.
  • "Nothing found yet" is not a failure. Findings only appear when a 20-minute chunk finishes, which can take an hour. The screen tells you what it is waiting for.
  • Close streaming software before a run. On a machine with 8 GB of memory this is worth real time, and there is no setting for it.
  • Plug the charger in. On battery, Windows caps the processor hard whatever the settings say — worth more than every other tweak combined.

If something goes wrong

Don't delete and re-download — run a checker instead

Three files sit in the app folder. Double-click — nothing to type.

FileUse it when
Check My System.batAnything at all. Start here — it reports what is missing and fixes the most common cause on its own.
Fix Missing Model.batThe error mentions a missing text model.
Check Run Speed.batIt is running but seems far too slow, or you want to tune the machine.

Each saves a small text file to your Desktop. That file is the single most useful thing you can send us.

Re-downloading the app rebuilds the parts that already work and cannot fix the two things that actually fail. Runs also resume where they stopped, so nothing is lost by fixing a problem and starting again.

Still stuck? Post in the Discord and drag that Desktop file straight into the message. Someone has probably hit it already.
